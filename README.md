# nonebot-plugin-fishmemory 🐟

> 给 bot 一份「关于每个人的长期记忆」：从聊天里自动抽名字 / 年龄 / 生日 / 喜好，
> **正则抽取，零 LLM 开销**；注入提示词时**带字数上限**，不会越滚越长。

从跑了半年的 QQ 机器人（[肥鱼人设](https://github.com/173ababah)）里拆出来的记忆模块。

## 命令

| 命令 | 说明 |
|------|------|
| `/记忆` | 看 bot 记得你什么 |
| `/记住 我怕黑` | 手动记一条 |
| `/忘记` | 清空自己的记忆 |
| `/忘记 喜欢 奶茶` | 删掉某一条（`喜欢`/`讨厌`/`事实` 可简写） |

## 给别的插件用（推荐用法）

```python
from nonebot_plugin_fishmemory import learn, mem_block

# 收到消息时（纯正则，不花钱）
learn(user_id, text)          # → ["名字=小明", "喜欢=奶茶"]

# 拼 system prompt 时
block = mem_block(user_id)    # → "【你记得关于这个人的事】小明，20 岁；喜欢奶茶、猫"
if block:
    system_prompt += "\n" + block
```

## 三条设计取舍

### 1. 抽取用正则，不用模型

每句话都过一次大模型 = 每条消息都花钱。"我叫X / 今年N岁 / 我喜欢Y / 记住…"这类表达
正则能覆盖 90%，剩下 10% 让用户自己 `/记住`。

### 2. 单值覆盖、列表追加、只留最近 N 条

- `name / age / birthday / gender`：**覆盖写**（改口就该记新的）
- `likes / dislikes / facts`：**追加 + 去重 + 只留最近 N 条**（喜好会变，留太多互相打架）

### 3. 垃圾过滤（线上真踩过）

群里出现过「名字=###」「喜欢=什么」这种。所以：

- `JUNK` 表挡掉 什么/啥/哈哈/嗯/的/了/这个/那个 …（约 30 个词）
- 值里必须有中文/字母/数字，纯 `###`、`。。。` 一律不记
- **但不要用"长度 < 2"当标准** —— 「我喜欢猫」「我讨厌雨」都是合法的一条，
  这条规则一开始写上，直接把单字喜欢全过滤了（测试抓到的）

## ⚠️ 一个正则上的坑（值得单独说）

`我喜欢奶茶也喜欢猫` 会被 greedy 吃成一条 `奶茶也喜欢猫`，所以排除字符里必须有 **也/还/又/和、**：

```python
_STOP = r"([^\s，,。.!！?？也还又和、]{1,12})"
```

然后再补一条 `(?:也|还|又)喜欢…` 去接第二句。两处缺一个就会少记或记错。
